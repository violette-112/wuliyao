# Tomodachi Create

朋友收集 梦想生活（Tomodachi Life: Living the Dream）图案设计工具

为 Switch 游戏《朋友收集 梦想生活》玩家设计的图案转换工具。上传任意图片，系统自动将其像素化、映射到游戏 84 色调色板、应用所选服装模板的遮罩，生成一张可逐格对照临摹的编号图纸。

## 功能特性

- **4种服装模板**：简易T恤、短袖T恤、坦克背心、长袖T恤，带可视化遮罩预览
- **图片上传**：支持拖拽/点击上传 JPG/PNG/WEBP/GIF（最大 10MB）
- **颜色量化**：自实现 Median Cut 算法，可限制颜色数量（6/8/12/16/24/自动）
- **游戏调色板映射**：84色完整调色板（7×11基础色 + 7强调色），使用 Redmean 感知色差公式
- **笔刷精度**：支持 4px(64×64) / 8px(32×32) / 16px(16×16) 三种网格
- **实时调整**：亮度、饱和度滑块，显示网格线/编号开关
- **导出功能**：下载图纸 PNG、复制颜色列表（含 HEX 和游戏坐标）
- **纯前端处理**：所有图像处理均在浏览器本地完成，图片不会上传

## 技术栈

- React 18 + Vite
- TailwindCSS
- Canvas API（图像处理）
- 自实现 Median Cut + Redmean 色差算法

## 启动命令

```bash
npm install
npm run dev
```

## 部署

纯静态网站，可直接部署到 Vercel / GitHub Pages / Netlify 等平台。

```bash
npm run build
```

构建产物在 `dist/` 目录。

## 游戏技术规格

- 游戏内画布：256×256 游戏像素
- 笔刷模式：Pixel-perfect 模式
- 笔刷尺寸：4px / 8px / 16px / 32px
- 默认工具使用 8px 笔刷 → 32×32 绘制网格（共 1024 格）
- 游戏调色板：84 种颜色（7×11 基础色 + 7 强调色）
- 颜色坐标格式：R（行）C（列），如 R3·C9
- 游戏内需开启「专业画师模式」才能使用完整 84 色
